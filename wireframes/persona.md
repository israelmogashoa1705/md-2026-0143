# User Persona

Naledi, a keyboard and screen-reader user.
28 years old
Residing in Johannesburg, South Africa

## About
Naledi is an adult community member who needs to book routine healthcare appointments online. She uses a screen reader to navigate websites and prefers completing administrative tasks independently.

## Technical configuration
Operating system: Windows 11.
Browser: Mozilla Firefox, current supported release.
Assistive technology: NVDA screen reader.
Input: Keyboard only, using Tab, Shift+Tab, Enter, Space, arrow keys, and screen-reader navigation commands.
Display: Standard desktop monitor with browser zoom adjusted when needed.

## Accessibility requirements
Naledi relies on meaningful page titles, logical heading levels, correctly associated form labels, descriptive link text, accessible status announcements, and visible keyboard focus. She needs errors to be identified in text and associated with the relevant fields.

## Pain points
Forms that rely on placeholder text instead of persistent labels.
Custom dropdowns that cannot be operated with the keyboard.
Validation messages that appear visually but are not announced.
Search results that update without communicating the number of results.
Focus moving unexpectedly after a page or section changes.
Low-contrast text and controls that are difficult to distinguish.

## Primary goals
Find an appropriate clinic service.
Search and filter available services independently.
Select a practitioner and appointment time.
Complete the booking form without losing context.
Identify and correct validation errors.
Review the appointment details before confirmation.
